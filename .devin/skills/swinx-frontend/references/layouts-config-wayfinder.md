# Layouts, Config & Wayfinder API Reference — Inertia v3

> Read this file when working with layouts, Head, config/inertia.php, HandleInertiaRequests, or Wayfinder.

---

## Layouts

### Standard layout (wrapper in template)

```vue
<script setup>
import AppLayout from '@/layouts/AppLayout.vue';
const breadcrumbs = [{ title: 'Contacts' }, { title: 'Edit' }];
</script>

<template>
    <AppLayout :breadcrumbs="breadcrumbs">
        <!-- page content -->
    </AppLayout>
</template>
```

### Persistent layouts (survive navigation)

Layout stays mounted across navigations — state, timers, and listeners persist.

```vue
<script setup>
import PersistentLayout from '@/layouts/PersistentLayout.vue';

// Declare via defineOptions — NOT wrapping in template
defineOptions({ layout: PersistentLayout });
</script>

<template>
    <!-- No layout wrapper — renders into layout's slot -->
    <div>Page content</div>
</template>
```

### Layout props — static via tuple

```typescript
defineOptions({
    layout: [
        AppLayout,
        {
            breadcrumbs: [
                { title: 'Layouts & Head' },
                { title: 'Layout Props' },
            ],
        },
    ],
});
```

### Layout props — dynamic from page

```typescript
import { setLayoutProps, resetLayoutProps } from '@inertiajs/vue3';

// Set from anywhere in the page
setLayoutProps({ subtitle: 'Custom subtitle' });

// Reset to defaults
resetLayoutProps();
```

Layout declares props with defaults:

```vue
<script setup>
defineProps({
    subtitle: { type: String, default: '' },
    breadcrumbs: { type: Array, default: () => [] },
});
</script>
```

### Nested layouts

```typescript
defineOptions({
    layout: [OuterLayout, InnerLayout], // Array = nested
});
```

## Head & Title

### Basic

```vue
import { Head } from '@inertiajs/vue3';

<!-- Shorthand -->
<Head title="Contacts" />
<!-- Renders: "Contacts - App Name" via title callback -->

<!-- Full control -->
<Head>
    <title>Custom Title</title>
    <meta name="description" content="Page description" />
    <link rel="canonical" href="https://example.com/contacts" />
</Head>
```

### Deduplication with `head-key`

```vue
<!-- Child component can override parent's meta by matching head-key -->
<Head>
    <meta head-key="description" name="description" content="Override" />
</Head>
```

### Title callback (app.ts)

```typescript
createInertiaApp({
    title: (title) => `${title} - Swinx`,
});
```

## Config — `config/inertia.php`

```php
return [
    'ssr' => [
        'enabled' => (bool) env('INERTIA_SSR_ENABLED', false),
        'url' => env('INERTIA_SSR_URL', 'http://127.0.0.1:13714'),
        'throw_on_error' => (bool) env('INERTIA_SSR_THROW_ON_ERROR', false),
    ],

    'pages' => [
        'ensure_pages_exist' => true,          // Catch missing components
        'paths' => [resource_path('js/pages')],
        'extensions' => ['js', 'jsx', 'svelte', 'ts', 'tsx', 'vue'],
    ],

    // NEW v3: expose which props are shared (instant visit optimization)
    'expose_shared_prop_keys' => true,

    // NEW v3: encrypt history state (prevents data access after logout)
    'history' => [
        'encrypt' => (bool) env('INERTIA_ENCRYPT_HISTORY', false),
    ],
];
```

### Key settings

| Setting | Default | Purpose |
|---------|---------|---------|
| `expose_shared_prop_keys` | `true` | Allows instant visits to carry shared props |
| `history.encrypt` | `false` | Encrypts page data in browser history |
| `pages.ensure_pages_exist` | `true` | Throws if Vue component file missing |

## HandleInertiaRequests Middleware — Shared Props

```php
class HandleInertiaRequests extends Middleware
{
    public function share(Request $request): array
    {
        return [
            ...parent::share($request),
            'name' => config('app.name'),
            'auth' => [
                'user' => $request->user(),
            ],
            'sidebarOpen' => (bool) $request->cookie('sidebar_open', true),
        ];
    }
}
```

Access shared props:

```typescript
import { usePage } from '@inertiajs/vue3';
const page = usePage();
const user = page.props.auth.user;
const appName = page.props.name;
```

## Wayfinder — Type-Safe Routes

Auto-generated by `@inertiajs/vite` plugin from Laravel controllers.

### Import patterns

```typescript
import { index, store, update, destroy } from '@/wayfinder/App/Http/Controllers/ContactController';
```

### Three return formats

```typescript
// action() → { url: string, method: string } — for router/useForm
const action = update({ contact: 42 });
// → { url: '/contacts/42', method: 'put' }

// .url() → string — URL only, for <Link> or router.visit
const url = update.url({ contact: 42 });
// → '/contacts/42'

// .form() → { action: string, method: string } — for <Form> component
const formProps = update.form({ contact: 42 });
// → { action: '/contacts/42', method: 'put' }
```

### Usage with each API

```typescript
// useForm
form.submit(update({ contact: id }), { preserveScroll: true });

// router
router.visit(index.url());

// <Link>
<Link :href="index.url()" prefetch>Contacts</Link>

// <Form>
<Form v-bind="store.form()" :set-defaults-on-success="true">
```

### Typed page props and models

```typescript
// Page props — matches controller's Inertia::render() data
import type { EditProps } from '@/wayfinder/types/Inertia/Pages/Contacts/Edit';
defineProps<EditProps>();

// Models
import type { Contact } from '@/wayfinder/types/App/Models/Contact';
```

### Key gotcha

| Method | Returns | Use with |
|--------|---------|----------|
| `action()` | `{ url, method }` | `router`, `useForm.submit()` |
| `.url()` | `string` | `<Link :href>`, `router.visit()` |
| `.form()` | `{ action, method }` | `<Form v-bind>` |

Do NOT use `.form()` with `router.visit()` — it returns `{ action }` not `{ url }`.
