## Admin & Dashboard

### Goals

* Analytics for Gold economy:

  * Total Gold earned/spent.
  * Top students by Gold.
  * Gold distribution per event.
* Manage redemptions, stock, and event statistics.

## Advanced Features

* **Achievements & Badges**: Award students for milestones.
* **Flexible Event Rewards**: Add table `event_rewards` for multiple reward conditions (e.g., participation vs. competition winners).
* **Notifications**: Push alerts when Gold is earned or reward shipped.
* **Gamification**: Leaderboards per club/campus.

## Summary

This design introduces a **Gold-based reward ecosystem** tightly integrated with **events** and **clubs**. It enhances student engagement while ensuring transparency (via wallet transactions) and scalability (via unified event schema). The phased approach allows gradual rollout: from basic wallets → events → clubs → store → analytics → gamification.
