# Naming Guardrails (Short)

- Backend: Modules/Models/Controllers/Actions/Queries use PascalCase and singular nouns.
- Routes: `{module}.{resource}.{action}`; API paths are kebab-case.
- Frontend: Pages/Components in PascalCase; composables start with `use`.

Details: `docs/rules/naming.md`.
