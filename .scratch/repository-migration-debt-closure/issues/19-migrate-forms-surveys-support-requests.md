# Migrate Forms, Surveys and Student Support requests

Status: ready-for-human

Portal impact: student

## Parent

[Close repository-wide Migration Debt](01-close-repository-wide-migration-debt.md)

## What to build

Give Forms, Surveys, responses/results, Query Tickets, and related Student Support requests explicit owner boundaries and migrate their staff/student workflows, reports, notifications, and API/UI contracts end to end.

## Acceptance criteria

- [x] Each workflow has an explicit owner and supported commands/queries outside frozen services/controllers.
- [x] Form targeting, submissions, survey settings/results, support-ticket state, authorization, and reporting remain compatible.
- [x] Staff UI and student API surfaces use current route, validation, form, table, and `ApiResponse` conventions.
- [x] Student references and notifications cross boundaries through approved contracts.
- [x] Legacy Forms/Surveys/Query paths have zero supported callers before retirement.
