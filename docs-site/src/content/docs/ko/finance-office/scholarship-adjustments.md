낙제 과목이 있는 학생을 검토하고, 면담 내용을 기록하며, 다음 학기 장학금을 줄일지 결정할 때 사용합니다. 원래 장학금은 수정하거나 삭제하지 않고, 영향받는 학기에만 별도 **조정 건**을 생성합니다.

**접근 권한.** 조회는 `view_scholarship_adjustment`, 결정 승인은 `approve_scholarship_adjustment`.

**위치.** **Discounts & Funding → Scholarship Adjustments**.

> 🎬 _스크린샷/영상: (추후 추가 예정)_

## 전체 흐름

```text
1. 대상 학생 찾기  →  2. 면담 일정 잡기 & 기록  →
3. 학생 확인  →  4. 결정 & 승인  →
5. 학비에 반영  →  6. 다음 학기: 복원 또는 재검토
```

## 1. 대상 학생 찾기

**화면.** 목록 화면 우측 상단의 **Tìm sinh viên cần xét**(대상 학생 찾기) 버튼을 클릭하면 후보 검색 화면이 열립니다.

**절차**

1. **대상 학기**(장학금 변경이 적용될 학기)를 선택합니다.
2. **출발 학기**(선택한 대상 학기보다 **이전에** 시작한 학기만 표시)를 선택합니다.
3. 시스템이 각 학생의 낙제 과목과 함께 검토 가능한 학생 목록을 자동으로 표시합니다.
4. 건을 열고 싶은 학생을 체크합니다(전체 선택은 필수 아님).
5. **Mở đợt xét cho N sinh viên**(N명 검토 시작) 버튼을 클릭합니다.

**숨겨진 인원 수 확인.** 목록 제목 바로 아래에 표시되지 않은 학생 수가 나옵니다: 이미 검토 중, 아직 확정 성적 없음, 또는 이번 학기에 이미 학비가 청구됨(청구된 학생은 더 이상 후보에서 제외).

**빨간 배지 주의.** **Cần kiểm tra điểm thủ công**(수동 성적 확인 필요) 배지는 합격/불합격 계산 오류 수정(2026-07-04) 이전에 확정된 성적임을 뜻합니다 — 결정 전에 원본 성적을 다시 확인하세요.

## 2. 건 열기 & 면담 일정 잡기

검토 배치가 열리면 학생마다 개별 건이 생성됩니다 — 목록 마지막 열의 **Mở**(열기)를 클릭합니다.

**"이 학생이 대상이 된 이유" 패널**에는 출처(시스템 자동 감지 또는 수동 추가), 현재 장학금, 낙제 과목(수강 횟수와 성적 확정일 포함)이 표시됩니다.

**면담 일정 잡기**

1. **면담** 패널에서 **날짜**와 **시간**을 선택합니다.
2. **Đặt lịch phỏng vấn**(면담 예약) 버튼을 클릭합니다.

**면담 후 기록 작성**

1. 상태가 **Đã hẹn lịch**(예약됨)로 바뀌면 면담 패널에 **면담록** 입력란이 나타납니다.
2. 면담에서 합의된 내용을 입력합니다.
3. **Lưu biên bản và gửi sinh viên xác nhận**(면담록 저장 및 확인 요청)을 클릭하면 시스템이 자동으로 학생에게 알림을 보냅니다. 추가 작업은 필요 없습니다.

**참고.** 면담록은 버전이 관리됩니다(**N번째 수정본**). 학생 확인 후 면담록을 수정하면 새 버전이 생성되고 확인이 초기화됩니다.

## 3. 학생 확인

학생은 Student Portal에서 확인합니다. **학생 확인** 패널에 상태가 바로 표시됩니다: *대기 중*, *확인함*, *이의 있음*, *기한 초과*, 또는 *승인자가 이의 기각*.

**학생이 아직 응답하지 않은 경우(대기 중/기한 초과):** 직원이 대신 확인할 수 있습니다.

1. **학생에게 어떻게 연락했고 무엇에 동의했는지**를 입력합니다.
2. **Xác nhận thay sinh viên**(대신 확인) 버튼을 클릭합니다.

**학생이 이의를 제기한 경우(이미 이의로 응답함):** 직원이 대신 확인해서는 **안 됩니다**. 두 가지 정직한 방법:

- **면담록 수정** — 수정된 내용을 입력하고 **Lưu biên bản đã sửa và hỏi lại**(수정된 면담록 저장 및 재요청)을 클릭합니다. 학생이 새 버전에 다시 확인합니다.
- **이의 기각** — 승인 권한자만 가능하며, 사유(최소 10자)를 입력하고 **Bác bỏ phản đối**(이의 기각)를 클릭합니다. 학생의 반대 의견은 기록에 그대로 남고, "확인함"으로 덮어써지지 않습니다.

## 4. 결정 & 승인

건이 **면담 완료** 또는 **승인 대기** 상태일 때만 가능합니다.

**제안 단계**

1. **처리 방식**을 선택합니다: *유지*, *삭감*, *전액 정지*, *보류*, 또는 *취소*.
2. **삭감**을 선택한 경우: **학생이 유지할 장학금 비율**을 입력합니다 — 단위는 원래 장학금 유형(학비 대비 % 또는 고정 금액)을 따르며, 입력값은 **삭감 후 남는 값**이지 삭감되는 값이 아닙니다.
3. **이번 학기 학비 영향** 패널이 입력과 동시에 실시간으로 갱신됩니다: 학기 학비, 삭감 전/후 장학금 지원액, 삭감 전/후 학생 납부액. 대상 학기에 아직 청구서가 없으면 청구서 발행 시 자동 반영된다고 안내합니다.
4. **처리 방식 선택 사유**를 입력합니다(필수).
5. **Gửi đề xuất quyết định**(결정 제안 제출) 버튼을 클릭합니다.

**미확인 시 차단.** 결정이 학비를 늘리는 경우(*삭감* 또는 *전액 정지*)인데 학생이 아직 면담록을 확인하지 않았다면 제출이 차단됩니다 — 3단계로 돌아가세요.

**승인 단계.** 제출 후 건은 **승인 대기** 상태가 되고 양식은 읽기 전용으로 잠깁니다.

- 승인 권한자가 **Duyệt quyết định này**(이 결정 승인)를 클릭하면 제안대로 확정됩니다.
- 또는 **Sửa lại quyết định**(결정 수정)을 클릭해 양식을 다시 열어 수정 후 재제출할 수 있습니다.

**승인 후.** 양식 대신 요약 정보가 표시됩니다: 처리 방식, 삭감 전/후 장학금 비율, 대상 학기, 사유, 제안자/승인자와 시각.

## 5. 학비에 반영

승인 후 건은 다음 중 하나의 상태로 전환되며, 결정 요약 바로 아래 표시됩니다.

| 상태 | 의미 |
| --- | --- |
| **학비에 반영됨** | 대상 학기 학비가 결정대로 업데이트됨. |
| **유지** | 학비 변경 없음. |
| **취소됨** | 장학금이 취소됨. |
| **재무 확인 필요** | 자동 반영 불가(예: 청구서가 이미 발행되었거나 결제됨) — Finance가 수동 처리. |
| **해당 없음** | 대상 학기가 청구 일정상 학비를 청구하지 않음. |
| **승인됨**(청구서 미발행) | 대상 학기 청구서 발행 시 자동 반영됨. |

**참고.** 이미 발행되었거나 결제된 청구서는 자동으로 소급 수정되지 않습니다.

## 6. 다음 학기: 복원 또는 재검토

영향받은 학기 성적이 확정되면 시스템이 자동으로 재평가합니다:

- 검토 대상 범위에서 더 이상 낙제가 없으면 → 다음 학기 원래 장학금 **복원**을 자동 제안.
- 계속 낙제하면 → **새 검토 건**을 엽니다. 기존 결정을 자동으로 연장하지 않습니다.

복원은 이전 조정 건을 삭제하지 않으며, 이전 학기에 이미 발행된 청구서를 자동 수정하지 않습니다.

## 건 상태 (빠른 참조)

`식별됨 → 면담 예약됨 → 면담 완료 → 학생 확인 대기 → 승인 대기 → 승인됨 → 학비에 반영됨 → 종료됨`

발생 가능한 부가 상태: **학생 이의 제기**, **학생 불참**, **확인 기한 초과**, **유지**, **취소됨**, **재무 확인 필요**, **해당 없음**.
