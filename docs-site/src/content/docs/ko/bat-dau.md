이 장은 시스템에 접속하고 화면 구성을 이해하기 위한 것입니다. 한 번만 읽으면 이후 모든 장을 따라갈 수 있습니다.

## 로그인

**용도.** 학교에서 발급한 계정으로 시스템에 접속합니다.

**절차**

1. 학교에서 안내한 Portal 주소를 엽니다.
2. **Sign in with Google**(Google로 로그인)을 누릅니다.
3. 학교에서 발급한 이메일 계정을 선택합니다.

**유의 사항**

- 이 시스템은 **Google 로그인만 지원합니다.** 별도의 비밀번호 입력란은 없습니다.
- 이메일 주소와 함께 오류가 표시되면 해당 주소에 아직 접근 권한이 없다는 뜻입니다. 관리자에게 계정 등록을 요청하십시오.
- 개인 계정으로 로그인하는 것이 가장 흔한 실수입니다. 화면 오른쪽 위에 표시된 이메일을 확인하십시오.

## 캠퍼스 선택

**용도.** 근무 중인 캠퍼스를 선택합니다. 이후 표시되는 모든 자료, 즉 학생·개설 강좌·강의실·등록금은 선택한 캠퍼스에 속한 것입니다.

**절차**

1. 로그인하면 **Select Your Campus** 화면에 접근 가능한 캠퍼스가 표시됩니다.
2. 근무하는 캠퍼스 카드를 누릅니다. 선택된 카드에는 파란 테두리가 생깁니다.
3. 확인하여 시스템으로 들어갑니다.
4. 다시 선택하려면 **Clear Selection**(선택 해제)을 누르고 다른 캠퍼스를 고릅니다.

**유의 사항**

- 접근 가능한 캠퍼스가 하나뿐이면 시스템이 자동으로 선택합니다.
- 현재 캠퍼스는 화면 왼쪽 위 시스템 이름 아래 `Campus: ...` 줄에 항상 표시됩니다.
- 잘못된 캠퍼스에 자료를 입력하면 되돌리기 어렵습니다. 자료를 새로 만들기 전에 반드시 `Campus:` 줄을 확인하십시오.

## 화면 구성

화면은 세 부분으로 나뉩니다.

- **왼쪽 열 — 메뉴.** 모든 기능이 업무 종류별로 묶여 있습니다.
- **상단.** 현재 열려 있는 화면 이름과 돌아가는 경로.
- **가운데.** 실제 작업 영역으로, 요약 카드·필터·자료 표가 표시됩니다.

주요 메뉴 그룹은 다음과 같습니다.

| 메뉴 그룹 | 담당 업무 |
| --- | --- |
| Overview | 요약 화면 |
| Academic Operations | 교육과정, 학기, 개설 강좌, 출석, 성적, 교원 |
| Students | 학생 기록, 등록, 학적 처분 |
| Reports & Audits | 보고서 및 자료 대조 |
| Finance | 등록금 부과, 수납, 대사, 장학금, 요금제, 할인 쿠폰 |
| Store & Clubs | Gold 교환 스토어, 학생 동아리 |
| Campus | 강의실, 예약, 행사 |
| Forms & Surveys | 양식 및 설문 |
| Communications | 이메일 및 알림 |
| Administration | 사용자, 권한, 시스템 설정 |

**중요.** 메뉴는 본인 권한에 따라 표시됩니다. 동료와 보이는 항목이 다를 수 있습니다. 항목이 없다는 것은 권한이 없다는 뜻이지 시스템 오류가 아닙니다.

## 요약 화면(Dashboard)

**용도.** 선택한 캠퍼스의 현황을 빠르게 파악합니다.

**접근 권한.** 로그인한 모든 사용자.

**표시 내용**

- 집계: 상태별 학생 수, 교원 수, 학위과정 수, 그리고 사용 가능·사용 중·점검 중 강의실 수.
- 현재 학기: 학기 코드, 시작일과 종료일, 수강신청 기간, 신청 개시 여부.
- 처리할 알림: 학사 처분 대상 학생, 출석 문제, 학위과정 변경.
- 학위과정별 학생 분포 그래프.

**유의 사항.** 여기의 알림은 단서일 뿐입니다. 실제 처리는 학사 영역과 학생 영역에서 이루어집니다.

## 개인 계정

**절차**

1. 왼쪽 메뉴 열 **맨 아래**에 있는 본인 이름을 누릅니다.
2. 필요한 항목을 고릅니다. 프로필 보기, 설정, 로그아웃.

**유의 사항**

- Portal에는 비밀번호 변경 기능이 없습니다. 비밀번호는 Google 계정에서 관리하므로 Google 계정 페이지에서 변경하십시오.
- 공용 컴퓨터에서는 브라우저를 닫는 것만으로 부족합니다. 반드시 **로그아웃**하십시오.

## 대부분의 화면에서 반복되는 기능

Portal의 목록 화면은 다음 기능을 공통으로 사용합니다.

- **검색창** — 이름이나 코드를 입력해 빠르게 좁힙니다.
- **필터(Filters)** — 학기, 상태, 학위과정 등으로 범위를 줄입니다.
- **필터 해제(Clear filters)** — 예상한 자료가 보이지 않을 때 목록을 원래대로 되돌립니다.
- **표 위의 요약 카드** — 현재 필터에 따라 값이 바뀌는 집계 수치.
- **각 행 끝의 아이콘** — 해당 항목 보기, 수정, 삭제.

**유의 사항.** 목록이 비어 있는 것은 대개 자료가 없어서가 아니라 필터가 남아 있어서입니다. 문제를 보고하기 전에 **필터 해제**를 먼저 눌러 보십시오.
