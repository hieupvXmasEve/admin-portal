本指南面向在浏览器中使用 Portal 管理系统的 **教职员工**。无需技术知识。

学生和教师使用各自的独立门户，本指南不涉及。

## 从哪里开始

初次使用者请先阅读 [开始使用](/zh/bat-dau/)：登录、选择校区、如何阅读界面。只需读一次，后续所有章节都能看懂。

之后进入你负责的工作区域——下表十个区域对应九个菜单分组。

## 文档约定

- 菜单路径写作 **菜单分组 → 项目 → 子项目**。
- 界面上显示的名称目前是英文，因此本指南保留原文并在旁边加上中文注释。例如：**Programs（培养方案）**。
- 每个界面按四部分说明：*用途 · 谁可以访问 · 操作步骤 · 注意事项*。
- 如果指南中提到的某个项目不在你的菜单上，说明该账号尚未获得该项目的访问权限。请联系管理员。
