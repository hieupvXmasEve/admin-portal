用于审查因挂科被列入名单的学生，记录面谈过程，决定下一学期是否降低其奖学金比例。系统不修改或删除原始奖学金——只为受影响学期单独创建一条**调整档案**。

**谁能访问。** `view_scholarship_adjustment` 查看，`approve_scholarship_adjustment` 审批决定。

**入口。** **Discounts & Funding → Scholarship Adjustments**。

## 流程总览

```text
1. 查找待审学生  →  2. 安排面谈并记录  →
3. 学生确认  →  4. 决定与审批  →
5. 应用到学费  →  6. 下学期：恢复或重新审查
```

## 1. 查找待审学生

**界面。** 点击列表页右上角的 **Tìm sinh viên cần xét**（查找待审学生），打开候选人查询界面。

**步骤**

1. 选择**目标学期**（奖学金将受影响的学期）。
2. 选择**来源学期**（仅显示开始日期**早于**所选目标学期的学期）。
3. 系统自动列出**可纳入审查的学生**，附带各自的挂科科目。
4. 勾选想要开启档案的学生（无需全选）。
5. 点击 **Mở đợt xét cho N sinh viên**（为 N 名学生开启审查）。

**留意被隐藏的数量。** 列表标题下方一行会显示未展示的学生数：已在审查中、尚无最终成绩，或本学期已产生学费（一旦收费即不再纳入候选）。

**注意红色标记。** **Cần kiểm tra điểm thủ công**（需人工复核成绩）标记表示该成绩在及格/不及格计算修复（2026-07-04）之前已确定——决定前请复核原始成绩。

## 2. 开启档案并安排面谈

审查批次开启后，每名学生拥有独立档案——点击列表最后一列的 **Mở**（打开）进入。

**"该学生被列入名单的原因"面板**显示：来源（系统自动识别或手动添加）、当前奖学金、挂科科目及第几次修读、成绩确定日期。

**安排面谈**

1. 在**面谈**面板选择**日期**和**时间**。
2. 点击 **Đặt lịch phỏng vấn**（安排面谈）。

**面谈结束后记录面谈录**

1. 状态变为**已安排**后，面谈面板出现**面谈记录**文本框。
2. 输入面谈达成的内容。
3. 点击 **Lưu biên bản và gửi sinh viên xác nhận**（保存记录并发送学生确认）——系统自动通知学生，无需额外操作。

**注意。** 面谈记录带版本号（**第 N 次修改版**）。学生确认后再修改记录会生成新版本，需重新确认。

## 3. 学生确认

学生在 Student Portal 上确认。状态直接显示在**学生确认**面板：*待回复*、*已同意*、*不同意*、*逾期未回复*，或*审批人已驳回异议*。

**若学生尚未回复（待回复/逾期）：** 职员可代为确认。

1. 填写**你如何联系学生以及学生同意的内容**。
2. 点击 **Xác nhận thay sinh viên**（代学生确认）。

**若学生已表示不同意：** 职员**不得**代为确认。可选两条路径：

- **修改面谈记录**——输入修订后的内容，点击 **Lưu biên bản đã sửa và hỏi lại**（保存修订记录并重新询问）。学生对新版本重新确认。
- **驳回异议**——仅限有审批权限者，需填写理由（至少 10 字），点击 **Bác bỏ phản đối**（驳回异议）。学生的不同意意见仍保留在档案上，不会被改写为"已同意"。

## 4. 决定与审批

仅在档案处于**已面谈**或**待审批**状态时可操作。

**提交提案**

1. 选择**处理方式**：*维持不变*、*削减奖学金*、*全额暂停*、*暂缓决定*，或*取消奖学金*。
2. 若选择**削减奖学金**：填写**学生保留的奖学金比例**——单位随原奖学金类型（学费百分比或固定金额），填写的是**削减后剩余的部分**，不是被削减的部分。
3. **本学期学费影响**面板会随输入实时更新：学期学费、削减前后的奖学金抵扣、削减前后学生应付金额。若目标学期尚无账单，会提示调整将在账单开出时自动生效。
4. 填写**处理方式的理由**（必填）。
5. 点击 **Gửi đề xuất quyết định**（提交决定提案）。

**未确认时会被拦截。** 若决定会增加学生应付金额（*削减*或*全额暂停*）而学生尚未确认面谈记录，提交会被拦截——需返回第 3 步。

**审批。** 提交后档案转为**待审批**，表单锁定为只读：

- 拥有审批权限者点击 **Duyệt quyết định này**（批准此决定），按原提案生效；或
- 点击 **Sửa lại quyết định**（修改决定）重新打开表单编辑后再提交。

**审批完成后。** 表单被替换为摘要：处理方式、削减前后的奖学金比例、目标学期、理由、提案人/审批人及时间。

## 5. 应用到学费

审批后，档案进入以下状态之一，显示在决定摘要下方：

| 状态 | 含义 |
| --- | --- |
| **已应用到学费** | 目标学期的学费已按决定更新。 |
| **维持不变** | 学费不变。 |
| **已取消** | 奖学金已取消。 |
| **需财务复核** | 系统无法自动更新（例如账单已开出或已支付）——由 Finance 手动处理。 |
| **不适用** | 目标学期按收费时间线不收取学费。 |
| **已批准**（账单未开出） | 目标学期账单开出时将自动生效。 |

**注意。** 已开出或已支付的账单不会被自动追溯修改。

## 6. 下学期：恢复或重新审查

受影响学期的成绩确定后，系统自动重新评估：

- 审查范围内不再挂科 → 自动提议下学期**恢复**原奖学金比例。
- 继续挂科 → 开启**新的审查档案**，不会自动延续旧决定。

恢复不会删除此前的调整档案，也不会自动修改前一学期已开出的账单。

## 档案状态（速查）

`已识别 → 已安排面谈 → 已面谈 → 待学生确认 → 待审批 → 已批准 → 已应用到学费 → 已关闭`

可能遇到的分支状态：**学生不同意**、**学生未出席**、**确认逾期**、**维持不变**、**已取消**、**需财务复核**、**不适用**。
